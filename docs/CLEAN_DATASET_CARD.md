# WAXAL Combined Clean-Audio ASR Dataset (PRIVATE)

**Private working dataset for the Zindi Google WAXAL ASR Challenge. Do not
redistribute or make public without reviewing per-source licenses below.**

## Purpose

Cleaned, edge-silence-trimmed, quality-bucketed combination of the datasets our
pipeline already uses, with cleaned audio embedded so training runs can
`load_dataset` this repo directly instead of re-running audio preprocessing.

## Languages

Lingala (lin), Luganda (lug), Shona (sna).

## Splits

| Split | Content |
|---|---|
| `train` | clean bucket only (default training data) |
| `medium_train` | minor issues; opt-in via `extra_train_splits: [medium_train]` |
| `noisy_for_review` | suspicious rows; analysis only |
| `excluded_for_review` | severe audio/transcript mismatch, silent/stub audio, unusable transcripts |
| `validation` | FULL official validation (all buckets) with trimmed audio, for comparable evaluation |

## Cleaning method (preprocessing_version `clean_audio_v1`)

1. Decode from prepared source dataset; mono; resample to 16 kHz.
2. Conservative edge-silence trim: 30 ms frame RMS, speech = within 40 dB of
   loudest frame and above absolute floor 1e-4; 200 ms padding kept both sides;
   internal pauses untouched. If result < 0.3 s, keep original and flag.
3. Cleaned audio written as mono 16 kHz FLAC; SHA-256 hashes recorded for
   original array and cleaned file.
4. Quality buckets from post-trim stats (see `docs/DATA_QUALITY_AUDIT.md` in
   this repo for the exact rules and thresholds).

Known source defect motivating exclusion rules: `google/WaxalNLP` contains
clips of exactly 1.0 s with full-sentence transcripts (confirmed via
prediction autopsy + reference-length cross-check); these fall into
`excluded_for_review`.

## Row schema

`original_split`, `transcription`, `audio` (cleaned, embedded),

`silence_ratio`, `clipping_ratio`, `duration`, `preprocessing_version`,
`audio_hash_original`, `audio_hash_cleaned`.

`docs/CLEAN_AUDIO_DATASET_REPRODUCIBILITY.md`.

## Known limitations

- Source-side 1 s stub clips can only be excluded, not repaired.
- Trimming thresholds are conservative; some edge silence remains by design.
- Validation audio is trimmed; apply the same `trim_edges` at inference time
  for distribution consistency if models are trained on this data.
